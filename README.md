# Tic Tac Toe AI

## Description
This project is a Tic Tac Toe game developed using C++.

Two players can play the game in the terminal.

## Features
- Interactive gameplay
- Board display
- Win detection
- Draw detection

## Technologies Used
- C++

## How to Run

1. Compile the program:
g++ main.cpp -o tictactoe

2. Run the executable:
./tictactoe
